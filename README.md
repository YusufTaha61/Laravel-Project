## 📌 About the Project
This project is a dynamic and scalable full-stack B2C e-commerce application developed using the Laravel framework. The system is designed with a secure Role-Based Access Control (RBAC) architecture to serve two main user types: Customers (User) and Administrators (Admin).

## 🚀 Key Features (Current State)
- **User Authentication & Role Management:** Secure registration/login processes utilizing Laravel Breeze, with database-driven `admin` and `user` role distinctions.
- **Admin Security Firewall (Middleware):** A custom control mechanism that prevents unauthorized users from accessing the admin panel.
- **Dynamic Product & Category Management (CRUD):** Adding, listing, and updating products in the system via the management panel.
- **Relational Database Architecture:** Linking products to their creators (admins) and categories using Foreign Keys to ensure data integrity.

## 🚧 Upcoming Features (Work in Progress)
- Dynamic Shopping Cart Operations (Add, Remove, Calculate Total Price)
- Secure Checkout and Order Creation
- Customer Order Tracking Dashboard
- Quality Assurance (QA) Tests and Form Validations
